Le projet

Cortex est un agent IA autonome concu pour optimiser le workflow d'un developpeur. Il ne se contente pas de repondre a des questions — il orchestre des LLM, gere sa propre memoire, parle et ecoute en vocal, genere des rapports, execute des commandes, et interagit avec Telegram, le web et les emails. Le tout depuis un dashboard temps reel accessible sur desktop et mobile.

L'idee : le logiciel de demain ne se clique plus. Il se parle. L'interface n'est plus un ecran avec des boutons — c'est une voix, une conversation, un agent qui comprend le contexte et agit en autonomie.

Architecture

Backend modulaire

Python stdlib — pas de framework, zero dependance lourde

Le backend est un serveur HTTP pur Python, decoupe en modules independants : config, routes, message pipeline, TTS, LLM, vault, orchestrateur de rapports, benchmark, et integration Telegram. Chaque module a une responsabilite claire.

config.py routes.py message.py llm.py tts.py vault.py orchestrator.py benchmark.py telegram_api.py

Frontend vanilla

HTML/CSS/JS — pas de React, pas de build

Dashboard responsive avec 10 modules JS, 5 fichiers CSS, et un seul HTML. Graphe vault interactif (Canvas), terminal xterm.js, graphiques Chart.js, animations orb/waveform. Accessible desktop et mobile.

Vanilla JS Chart.js xterm.js Canvas

Infrastructure

Local-first, accessible partout

Cortex tourne sur une Steam Deck reconvertie en serveur dev. Accessible en local et a distance via Tailscale. Terminal Claude Code interactif integre via WebSocket + PTY.
